Visao Geral

Stack Atual

  • Laravel 13 (PHP 8.3)
  • React 19 + Inertia.js
  • Tailwind CSS 4
  • SQLite
  • cPanel + FTP Deploy
→

Stack Nova

  • Next.js 15 (App Router) + TypeScript
  • React 19 (reaproveitado)
  • Tailwind CSS 4 (reaproveitado)
  • Supabase (PostgreSQL + Auth + RLS)
  • Vercel (git push deploy)

Por que migrar?

  • Deploy instantaneo com git push
  • Banco PostgreSQL gerenciado
  • Autenticacao pronta (Supabase Auth)
  • Multi-tenancy via RLS nativo
  • Uma unica linguagem (TypeScript)
  • Plano gratuito generoso

Row Level Security (Multi-tenancy)

Multi-tenancy sera implementado via RLS do PostgreSQL. Cada tabela com company_id recebe policies que garantem que o usuario so acesse dados da sua empresa.

Exemplo para tabela customers

-- Habilitar RLS
ALTER TABLE customers ENABLE ROW LEVEL SECURITY;

-- SELECT: usuarios so veem clientes da sua empresa
CREATE POLICY "Users can view own company customers"
ON customers FOR SELECT
USING (company_id IN (
  SELECT company_id FROM company_user
  WHERE user_id = auth.uid() AND is_active = true
));

-- INSERT: usuarios so inserem na sua empresa
CREATE POLICY "Users can insert in own company"
ON customers FOR INSERT
WITH CHECK (company_id IN (
  SELECT company_id FROM company_user
  WHERE user_id = auth.uid() AND is_active = true
));

-- UPDATE e DELETE: mesmo pattern

Aplicar o mesmo pattern em: vehicles, products, suppliers, service_orders, sales, quotes, purchases, stock_movements, warranties, financial_entries, cash_registers.
